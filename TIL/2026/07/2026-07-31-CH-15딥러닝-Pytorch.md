1-1. PyTorch

**PyTorch**

`신경망의 학습 과정을 직접 제어할 수 있는 딥러닝 라이브러리`

Keras에서는 `fit()`이 데이터 공급, 예측, 손실 계산, 미분, 가중치 수정을 자동으로 처리했다.

PyTorch에서는 이 과정을 직접 작성한다.

```plain text
Keras
→ 자동변속기
→ fit()으로 학습

PyTorch
→ 수동변속기
→ 학습 과정을 직접 작성
```

PyTorch의 기본 흐름은 다음과 같다.

```plain text
Tensor 준비
→ Dataset과 DataLoader 생성
→ nn.Module로 모델 정의
→ 손실 함수와 옵티마이저 설정
→ 학습 루프
→ 평가
→ 모델 저장
```

2-1. Tensor

**Tensor**

`PyTorch에서 데이터를 표현하는 다차원 배열`

Tensor는 NumPy 배열과 비슷하지만 두 가지 기능이 추가되어 있다.

```plain text
Tensor
= NumPy 배열
+ GPU 연산
+ 자동 미분
```

```python
import torch

t = torch.tensor([
    [1, 2, 3],
    [4, 5, 6]
])

print(t)
print(t.shape)
print(t.dtype)
```

- `shape` : Tensor의 형태
- `dtype` : 저장된 값의 자료형
- 1차원 Tensor : 벡터
- 2차원 Tensor : 행렬
- 3차원 이상 : 여러 차원의 데이터
2-2. Tensor 연산

Tensor의 연산 방식은 NumPy와 비슷하다.

```python
a = torch.tensor([1.0, 2.0, 3.0])

print(a + b)       # 덧셈
print(a * b)       # 원소별 곱셈
print(a.dot(b))    # 내적
```

인덱싱과 형태 변경도 가능하다.

```python

print(t)

```

```plain text
torch.arange(12)
→ 0부터 11까지 생성

reshape(3, 4)
→ 3행 4열로 변환
```

3-1. 자동 미분

**Autograd**

`연산 과정을 기록하고 자동으로 미분값을 계산하는 기능`

```python
x = torch.tensor(
    3.0,
    requires_grad=True
)

y = x ** 2
y.backward()

print(x.grad)
```

```plain text
y = x²
y를 x로 미분
→ 2x

x = 3
→ 기울기 6
```

- `requires_grad=True` : 해당 Tensor의 연산을 추적
- `.backward()` : 미분값 계산
- `.grad` : 계산된 기울기 확인
3-2. 복잡한 함수의 미분

```python
x = torch.tensor(
    2.0,
    requires_grad=True
)

y = x ** 3 + 2 * x

y.backward()

print(x.grad)
```

```plain text
y = x³ + 2x

미분
→ 3x² + 2

x = 2
→ 기울기 14
```

딥러닝에서는 수많은 가중치에 대한 미분값이 필요하다.

PyTorch는 `loss.backward()`를 통해 모든 가중치의 기울기를 자동으로 계산한다.

※ 미분은 실수에 대해 계산하므로 `3`이 아니라 `3.0`처럼 float Tensor를 사용

5-1. Dataset

**Dataset**

`전체 데이터를 보관하고 특정 위치의 입력값과 정답을 반환하는 데이터 창고`

```python
from torch.utils.data import Dataset

class FashionDataset(Dataset):
    def __init__(self, X, y):
        self.X = torch.tensor(
            X,
            dtype=torch.float32
        )

        self.y = torch.tensor(
            y,
            dtype=torch.long
        )

    def __len__(self):
        return len(self.X)

    def __getitem__(self, idx):
        return self.X[idx], self.y[idx]
```

- `__init__()` : 데이터를 Tensor로 변환해 저장
- `__len__()` : 전체 데이터 개수 반환
- `__getitem__()` : 특정 위치의 입력값과 정답 반환
- 입력 특성 : `float32`
- 정수 클래스 라벨 : `long`
```python
train_dataset = FashionDataset(
    X_train,
    y_train
)

test_dataset = FashionDataset(
    X_test,
    y_test
)
```

5-2. DataLoader

**DataLoader**

`Dataset에서 데이터를 일정한 배치 크기로 꺼내 모델에 공급하는 도구`

```python
from torch.utils.data import DataLoader

train_loader = DataLoader(
    train_dataset,
    batch_size=32,
    shuffle=True
)

test_loader = DataLoader(
    test_dataset,
    batch_size=32,
    shuffle=False
)
```

- `batch_size=32` : 한 번에 이미지 32장씩 학습
- `shuffle=True` : 훈련 데이터를 매 Epoch마다 섞음
- 평가 데이터는 순서를 섞지 않아도 됨
```python
batch_X, batch_y = next(
    iter(train_loader)
)

print(batch_X.shape)
print(batch_y.shape)
```

```plain text
Dataset
→ 데이터 창고

DataLoader
→ 데이터를 배치 단위로 공급하는 컨베이어 벨트
```

6-1. nn.Module

**nn.Module**

`PyTorch에서 신경망 모델을 정의할 때 상속받는 기본 클래스`

```python
import torch.nn as nn

class FashionNet(nn.Module):
    def __init__(self):
        super().__init__()

        self.layer1 = nn.Linear(
            784,
            128
        )

        self.relu = nn.ReLU()

        self.layer2 = nn.Linear(
            128,
            10
        )

    def forward(self, x):
        x = self.layer1(x)
        x = self.relu(x)
        x = self.layer2(x)

        return x
```

- `__init__()` : 사용할 층을 등록
- `forward()` : 데이터가 층을 통과하는 순서 정의
- `nn.Linear` : Keras의 Dense와 같은 완전연결층
- `nn.ReLU` : 은닉층의 활성화 함수
```python
model = FashionNet()

print(model)
```

```plain text
입력 784개
→ Linear 128
→ ReLU
→ Linear 10
→ 클래스별 점수 출력
```

6-2. 출력층에 Softmax를 넣지 않는 이유

PyTorch의 `nn.CrossEntropyLoss()`에는 Softmax 계산이 포함되어 있다.

따라서 다중 분류 모델의 출력층에는 Softmax를 직접 넣지 않는다.

```python
criterion = nn.CrossEntropyLoss()
```

```plain text
모델 출력
→ 클래스별 점수 Logit

CrossEntropyLoss
→ 내부에서 Softmax 처리
→ 실제 정답과 비교
```

※ 학습할 때는 Softmax를 넣지 않지만 확률을 확인할 때는 `torch.softmax()`를 사용할 수 있음

8-1. 학습 루프의 5단계

PyTorch 학습에서 가장 중요한 흐름은 다음 5단계이다.

```plain text
zero_grad()
→ 이전 기울기 초기화

model(X)
→ 예측

loss 계산
→ 예측과 정답 비교

backward()
→ 기울기 계산

step()
→ 가중치 수정
```

```python
epochs = 10

for epoch in range(epochs):
    model.train()
    total_loss = 0

    for batch_X, batch_y in train_loader:
        optimizer.zero_grad()

        outputs = model(batch_X)

        loss = criterion(
            outputs,
            batch_y
        )

        loss.backward()
        optimizer.step()

        total_loss += loss.item()

    avg_loss = (
        total_loss
        / len(train_loader)
    )

    print(
        f"Epoch {epoch + 1}, "
        f"Loss: {avg_loss:.4f}"
    )
```

8-2. 각 코드의 역할

```python
optimizer.zero_grad()
```

이전 배치에서 계산한 기울기를 초기화한다.

```python
outputs = model(batch_X)
```

입력 데이터를 모델에 넣어 예측값을 구한다.

```python
loss = criterion(outputs, batch_y)
```

예측값과 실제 정답을 비교해 손실을 계산한다.

```python
loss.backward()
```

손실을 각 가중치로 미분해 기울기를 계산한다.

```python
optimizer.step()
```

계산된 기울기를 이용해 가중치를 수정한다.

```plain text
Keras의 fit()
= Dataset
+ DataLoader
+ PyTorch 학습 루프 5단계
```

9-1. 기울기 누적

PyTorch의 `.backward()`는 기울기를 새 값으로 덮어쓰지 않고 기존 값에 더한다.

따라서 매 배치마다 `zero_grad()`를 사용해야 한다.

```python
optimizer.zero_grad()
loss.backward()
optimizer.step()
```

`zero_grad()`를 생략하면 이전 배치의 기울기가 계속 누적된다.

```plain text
정상 학습

이전 기울기 삭제
→ 현재 배치 기울기 계산
→ 가중치 수정
```

```plain text
zero_grad() 생략

이전 기울기
+ 현재 기울기
+ 다음 기울기
→ 잘못된 방향으로 가중치 수정
```

※ 에러가 발생하지 않고 학습만 잘못되므로 주의해야 함

9-2. 학습 순서

다음과 같이 `step()`을 `backward()`보다 먼저 실행하면 학습되지 않는다.

```python
# 잘못된 순서
optimizer.zero_grad()
loss = criterion(model(batch_X), batch_y)

optimizer.step()
loss.backward()
```

`step()`은 `backward()`가 계산한 기울기를 사용하므로 순서를 지켜야 한다.

```plain text
올바른 순서

zero_grad
→ forward
→ loss
→ backward
→ step
```

**Batch**

```python
loader = DataLoader(
```

```plain text
훈련 데이터 5,000개

→ 한 Epoch 동안 여러 번 가중치 수정
```

10-2. Batch Size에 따른 차이

```plain text
batch_size가 너무 작음
→ 가중치를 자주 수정
→ 학습 시간이 길어질 수 있음
→ 손실이 흔들릴 수 있음
```

```python
for batch_size in [1, 32, 5000]:

        train_dataset,
        batch_size=batch_size,
        shuffle=True

    print(
        batch_size,
        len(loader)
    )
```

일반적으로 `32` 또는 `64`가 자주 사용되지만 데이터와 환경에 따라 조정해야 한다.

11-1. eval()과 no_grad()

평가할 때는 두 가지 설정이 필요하다.

```python
model.eval()

with torch.no_grad():
    ...
```

- `model.eval()` : 모델을 평가 모드로 변경
- `torch.no_grad()` : 기울기 계산을 중단
- 평가 과정에서는 가중치를 수정하지 않음
- 메모리 사용량과 계산 시간을 줄일 수 있음
```python
model.eval()

correct = 0

with torch.no_grad():
    for batch_X, batch_y in test_loader:
        outputs = model(batch_X)

        preds = outputs.argmax(
            dim=1
        )

        correct += (
            preds == batch_y
        ).sum().item()

accuracy = correct / len(test_dataset)

print(f"정확도: {accuracy:.4f}")
```

- `argmax(dim=1)` : 클래스 점수가 가장 큰 위치를 최종 예측으로 선택
- `(preds == batch_y)` : 예측과 정답 비교
- `.sum().item()` : 맞힌 데이터 개수를 숫자로 변환
11-2. train()과 eval()

```plain text
학습 전
→ model.train()

평가 전
→ model.eval()
→ torch.no_grad()
```

`train()`과 `eval()`은 Dropout이나 Batch Normalization처럼 학습과 평가 시 동작이 다른 층에 중요하다.

13-1. 더 깊은 신경망

은닉층을 추가해 모델의 표현력을 높일 수 있다.

```python
class FashionNetV2(nn.Module):
    def __init__(self):
        super().__init__()

        self.flatten = nn.Flatten()

        self.net = nn.Sequential(
            nn.Linear(28 * 28, 128),
            nn.ReLU(),

            nn.Linear(128, 64),
            nn.ReLU(),

            nn.Linear(64, 10)
        )

    def forward(self, x):
        x = self.flatten(x)
        return self.net(x)
```

```plain text
이미지 (1, 28, 28)
→ Flatten
→ 784개 숫자
→ Linear 128
→ Linear 64
→ Linear 10
```

- `nn.Flatten()` : 이미지 형태를 1차원으로 펼침
- `nn.Sequential()` : 여러 층을 순서대로 묶음
- 출력층에는 Softmax를 넣지 않음
13-2. 학습 손실 기록

PyTorch에서는 Keras의 `history`처럼 학습 결과가 자동으로 저장되지 않는다.

직접 리스트에 기록해야 한다.

```python
train_losses = []

for epoch in range(10):
    model.train()
    total_loss = 0

    for batch_X, batch_y in train_loader:
        batch_X = batch_X.to(device)
        batch_y = batch_y.to(device)

        optimizer.zero_grad()

        loss = criterion(
            model(batch_X),
            batch_y
        )

        loss.backward()
        optimizer.step()

        total_loss += loss.item()

    avg_loss = (
        total_loss
        / len(train_loader)
    )

    train_losses.append(avg_loss)
```

```python
import matplotlib.pyplot as plt

plt.plot(
    train_losses,
    marker="o"
)

plt.xlabel("Epoch")
plt.ylabel("평균 손실")
plt.show()
```

손실이 감소하면 모델이 훈련 데이터에서 오답을 줄이고 있다는 의미이다.

14-2. 모델 복원

저장한 가중치를 불러올 때는 먼저 같은 구조의 모델을 생성해야 한다.

```plain text

→ 예측 또는 평가
```

## 💭 오늘의 회고

1. **배운 점**
- PyTorch : 신경망의 내부 학습 과정을 직접 제어하는 딥러닝 라이브러리
- Tensor : NumPy 배열에 GPU 연산과 자동 미분 기능이 추가된 자료구조
- `requires_grad=True` : 연산의 미분 과정을 추적
- `.backward()` : 자동으로 기울기 계산
- Dataset : 전체 데이터를 관리하는 데이터 창고
- DataLoader : 데이터를 배치 단위로 공급하는 도구
- `nn.Module` : PyTorch 모델을 정의하는 기본 클래스
- `__init__()` : 모델에서 사용할 층 등록
- `forward()` : 입력 데이터가 통과하는 순서 정의
- `nn.Linear` : 완전연결층
- `CrossEntropyLoss` : 다중 분류 손실 함수이며 Softmax를 내부에 포함
- PyTorch 다중 분류 모델의 출력층에는 Softmax를 직접 넣지 않음
- 학습 루프 : `zero_grad → forward → loss → backward → step`
- `zero_grad()`를 생략하면 이전 기울기가 누적되어 학습이 잘못될 수 있음
- `model.train()` : 모델을 학습 모드로 변경
- `model.eval()` : 모델을 평가 모드로 변경
- `torch.no_grad()` : 평가할 때 기울기 계산을 중단
- Batch Size : 한 번에 학습하는 데이터 개수
- GPU 사용 시 모델과 데이터를 모두 같은 device로 이동
- GPU Tensor를 시각화하거나 NumPy로 바꿀 때는 `.cpu()` 사용
- PyTorch에서는 학습 손실을 리스트에 직접 기록
- 틀린 이미지와 클래스별 정확도를 확인해야 모델의 약점을 찾을 수 있음
- 모델 저장은 `state_dict()`를 사용하는 것이 일반적
- 복원할 때는 같은 모델 구조를 만든 뒤 `load_state_dict()` 사용
- Keras와 PyTorch는 같은 딥러닝 원리를 서로 다른 방식으로 구현
- Keras는 간결한 구현에 강하고 PyTorch는 세밀한 제어에 강함
- 객체 분류는 이미지가 무엇인지 예측하고 객체 탐지는 위치와 종류를 함께 탐색
