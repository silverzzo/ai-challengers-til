1-1. 비지도학습

**비지도학습**

`정답 y 없이 특성 X만 이용해 데이터 안의 구조와 패턴을 찾는 학습`

- 지도학습 : `특성 X + 정답 y`
- 비지도학습 : `특성 X만 존재`
- 대표적인 방법 : 군집화, 차원 축소, 이상치 탐지
이번 실습에서는 쇼핑몰 고객의 나이, 연소득, 소비점수를 이용해 비슷한 고객끼리 자동으로 그룹화한다.

```plain text
나이·연소득·소비점수
→ 비슷한 고객 탐색
→ 고객 그룹 생성
```

```python
import pandas as pd

df = pd.read_csv("mall_customers.csv")

X = df[
    ["나이", "연소득_천달러", "소비점수"]
]
```

- 고객 ID : 데이터를 구분하기 위한 식별자이므로 제외
- 성별 : 이번 군집화 실습에서는 제외
- 정답 컬럼은 사용하지 않음
1-2. 군집화

**군집화 Clustering**

`특성이 비슷한 데이터끼리 자동으로 묶는 방법`

예를 들어 고객을 다음과 같이 나눌 수 있다.

```plain text
소득 높음 + 소비 높음
→ VIP 고객

소득 높음 + 소비 낮음
→ 잠재 VIP 고객

소득 낮음 + 소비 낮음
→ 절약형 고객
```

군집화 결과에는 처음부터 정답이나 그룹 이름이 존재하지 않는다.

모델이 만든 그룹의 평균 특성을 확인한 뒤 사람이 직접 의미를 해석하고 이름을 붙인다.

2-1. K-Means

**K-Means**

`데이터를 미리 정한 K개의 그룹으로 나누는 군집화 알고리즘`

동작 과정

```plain text
K개의 중심점 생성
→ 각 데이터를 가장 가까운 중심점에 배정
→ 그룹의 평균 위치로 중심점 이동
→ 중심점이 거의 움직이지 않을 때까지 반복
```

```python
from sklearn.cluster import KMeans

kmeans = KMeans(
    n_clusters=5,
    random_state=42,
    n_init=10
)

cluster_labels = kmeans.fit_predict(X)
```

- `n_clusters=5` : 데이터를 5개 그룹으로 나눔
- `random_state=42` : 실행할 때마다 같은 결과가 나오도록 설정
- `n_init=10` : 서로 다른 초기 중심점으로 10번 실행한 뒤 가장 좋은 결과 선택
- `fit_predict()` : 모델 학습과 군집 번호 생성을 한 번에 수행
```python
print(cluster_labels[:10])
print(kmeans.cluster_centers_)
```

- `cluster_labels` : 각 고객이 속한 군집 번호
- `cluster_centers_` : 각 군집의 중심점
- 군집 번호 `0, 1, 2`는 단순한 이름표이며 크기나 순서를 의미하지 않음

3-1. Inertia

**Inertia 관성**

`각 데이터와 자신이 속한 군집 중심점 사이 거리의 제곱합`

- 값이 작을수록 같은 군집의 데이터가 중심점 가까이에 모여 있음
- K가 커질수록 자연스럽게 작아짐
- 무조건 가장 작은 값을 선택하지는 않음
3-2. Elbow Method

**Elbow Method**

`K를 변경하면서 Inertia의 감소폭이 급격히 줄어드는 지점을 찾는 방법`

```python
inertias = []
K_range = range(1, 10)

for k in K_range:
    model = KMeans(
        n_clusters=k,
        random_state=42,
        n_init=10
    )

    model.fit(X)
    inertias.append(model.inertia_)
```

```python
plt.plot(
    K_range,
    inertias,
    marker="o"
)

plt.xlabel("클러스터 개수 K")
plt.ylabel("Inertia")
plt.title("Elbow Method")
plt.show()
```

```plain text
K 증가
→ Inertia 감소

감소폭이 크게 줄어드는 지점
→ 적절한 K의 후보
```

그래프가 팔꿈치처럼 꺾이는 지점을 선택한다.

이번 데이터에서는 `K=5` 이후 감소폭이 줄어들어 5개 군집을 적절한 후보로 판단했다.

3-3. Silhouette Score

**Silhouette Score 실루엣 점수**

`같은 군집끼리는 얼마나 가깝고 다른 군집과는 얼마나 멀리 떨어져 있는지 나타내는 값`

```python
from sklearn.metrics import silhouette_score

for k in range(2, 8):
    model = KMeans(
        n_clusters=k,
        random_state=42,
        n_init=10
    )

    labels = model.fit_predict(X)
    score = silhouette_score(X, labels)

    print(f"K={k}: {score:.4f}")
```

- 범위 : `1 ~ 1`
- `1`에 가까울수록 군집이 뚜렷함
- `0`에 가까우면 군집 간 구분이 애매함
- 음수라면 잘못된 군집에 배정되었을 가능성이 있음
```plain text
Elbow Method
→ Inertia 감소 형태 확인

Silhouette Score
→ 군집 품질을 숫자로 확인

비즈니스 활용 가능성
→ 실제로 해석하기 좋은 그룹 수인지 확인
```

※ 최적의 K는 하나의 지표만으로 결정하지 않고 여러 기준을 함께 고려

4-1. 차원 축소

**차원 축소**

`여러 특성이 가진 정보를 최대한 유지하면서 더 적은 수의 특성으로 줄이는 방법`

```plain text
나이·연소득·소비점수
→ 3개의 특성

PCA 적용
→ 주성분 1·주성분 2
→ 2개의 새로운 특성
```

차원을 줄이면 고차원 데이터를 사람이 확인하기 쉬운 2차원이나 3차원으로 시각화할 수 있다.

4-2. PCA

**PCA 주성분 분석**

`데이터가 가장 많이 퍼져 있는 방향을 찾아 새로운 축을 만드는 차원 축소 방법`

- 기존 특성들을 가중합해 새로운 주성분 생성
- 분산이 큰 방향을 우선적으로 선택
- 데이터의 주요 정보를 유지하면서 특성 수 감소
- 기존 컬럼을 그대로 선택하는 것이 아니라 새로운 축을 만듦
```python
from sklearn.decomposition import PCA

pca = PCA(n_components=2)

X_pca = pca.fit_transform(X)
```

- `n_components=2` : 주성분을 2개로 줄임
- `fit_transform()` : 주성분 방향을 학습하고 데이터를 변환
```python
plt.scatter(
    X_pca[:, 0],
    X_pca[:, 1],
    c=cluster_labels,
    cmap="viridis"
)

plt.xlabel("주성분 1")
plt.ylabel("주성분 2")
plt.title("PCA로 시각화한 군집 결과")
plt.show()
```

※ PCA가 군집을 만드는 것은 아님

```plain text
K-Means
→ 고객을 군집화

PCA
→ 만들어진 군집을 2차원으로 표현
```

4-3. 스케일링과 군집화

K-Means는 데이터 사이의 거리를 이용한다.

특성의 범위가 크게 다르면 숫자가 큰 특성이 거리 계산에 더 큰 영향을 줄 수 있다.

```plain text
스케일링 전
→ 연소득처럼 숫자가 큰 특성의 영향이 커질 수 있음

스케일링 후

```

※ 거리 기반 알고리즘에서는 스케일링이 중요

5-1. DBSCAN

**DBSCAN**

`데이터가 밀집된 영역을 기준으로 군집을 만드는 알고리즘`

```python
from sklearn.cluster import DBSCAN

dbscan = DBSCAN(
    eps=12,
    min_samples=5
)

dbscan_labels = dbscan.fit_predict(X)
```

- `eps` : 이웃으로 판단할 최대 거리
- `min_samples` : 하나의 밀집 지역으로 인정할 최소 데이터 수
- 군집 개수를 미리 정하지 않아도 됨
- 어느 군집에도 속하지 않는 이상치를 찾을 수 있음
```python
import numpy as np

print(np.unique(dbscan_labels))
```

- `1`은 어느 군집에도 속하지 않는 **노이즈 데이터**를 의미한다.
5-2. K-Means와 DBSCAN

```plain text
군집 개수를 미리 알고 있는가?
→ K-Means

불규칙한 형태의 군집인가?
→ DBSCAN

이상치도 함께 찾고 싶은가?
→ DBSCAN
```

※ DBSCAN의 결과는 `eps`와 `min_samples` 설정에 크게 영향을 받음

6-1. Feature Importance

**Feature Importance 특성 중요도**

`모델이 예측할 때 각 특성을 얼마나 중요하게 사용했는지 나타내는 값`

퇴사 예측 모델에서는 다음 질문에 답하는 데 사용한다.

```plain text
야근 여부가 중요한가?
월급이 중요한가?
근속 기간이 중요한가?
```

```python
import pandas as pd
from sklearn.ensemble import RandomForestClassifier

rf = RandomForestClassifier(
    n_estimators=100,
    random_state=42
)

rf.fit(X_train, y_train)
```

6-2. 트리 기반 내장 중요도

```python
importance = pd.Series(
    rf.feature_importances_,
    index=X.columns
).sort_values(ascending=False)

print(importance.head(10))
```

- Decision Tree, Random Forest 등 트리 기반 모델에서 사용
- 해당 특성으로 데이터를 나눴을 때 불순도가 얼마나 감소했는지 계산
- 값이 클수록 모델이 해당 특성을 많이 사용했다는 의미
- 모든 중요도의 합은 `1`
※ 중요도가 높다고 해당 특성이 결과의 직접적인 원인이라는 의미는 아님

6-3. Permutation Importance

**Permutation Importance 순열 중요도**

`특정 특성의 값을 무작위로 섞었을 때 모델 성능이 얼마나 떨어지는지 확인하는 방법`

```plain text
특성 하나를 무작위로 섞음
→ 해당 특성의 정보가 망가짐
→ 모델 성능 다시 측정
→ 성능이 크게 하락하면 중요한 특성
```

```python
from sklearn.inspection import permutation_importance

result = permutation_importance(
    rf,
    X_test,
    y_test,
    n_repeats=10,
    random_state=42
)

perm_importance = pd.Series(
    result.importances_mean,
    index=X.columns
).sort_values(ascending=False)

print(perm_importance.head(10))
```

- `n_repeats=10` : 각 특성을 10번 섞어 평균 중요도 계산
- 테스트 데이터의 실제 성능 변화를 기준으로 측정
- 트리뿐 아니라 다양한 모델에 적용 가능
- 반복해서 성능을 계산하므로 시간이 더 걸림
6-4. 중요도 방식 비교

```plain text
트리 모델의 중요도를 빠르게 확인
→ feature_importances_

모델 종류와 관계없이 중요도 확인
→ permutation_importance()
```

```python
from sklearn.metrics import classification_report

print(
```

주요 항목

- `precision` : 해당 클래스로 예측한 것 중 맞힌 비율
- `recall` : 실제 해당 클래스 중 맞힌 비율
- `f1-score` : Precision과 Recall의 균형
- `support` : 실제 해당 클래스의 데이터 개수
- `macro avg` : 각 클래스의 점수를 동일한 비중으로 평균
- `weighted avg` : 클래스별 데이터 개수를 반영해 평균
7-3. Macro Average와 Weighted Average

```python
from sklearn.metrics import recall_score

macro_recall = recall_score(
    y_test,
    y_pred,
    average="macro"
)

weighted_recall = recall_score(
    y_test,
    y_pred,
    average="weighted"
)
```

```plain text
macro avg
→ 모든 클래스를 같은 중요도로 평균
→ 소수 클래스의 낮은 성능도 크게 반영

weighted avg
→ 데이터 개수를 반영해 평균
→ 데이터가 많은 클래스의 영향이 큼
```

```plain text
소수 클래스도 중요
→ macro avg 확인

실제 데이터 비율을 반영
→ weighted avg 확인
```

※ 클래스가 불균형하다면 두 값을 함께 확인

8-1. 단일 데이터 분할의 한계

`train_test_split()`은 데이터를 한 번만 나눈다.

```python
for seed in [0, 1, 2]:
    X_train, X_test, y_train, y_test = train_test_split(
```

`random_state`가 달라지면 훈련·테스트 데이터 구성이 달라져 성능도 달라질 수 있다.


8-2. 교차검증

**교차검증 Cross Validation**

`데이터를 여러 번 다르게 나누어 학습과 평가를 반복한 뒤 평균 성능을 확인하는 방법`

```python
from sklearn.model_selection import cross_val_score

scores = cross_val_score(
    model,
    X_train,
    y_train,
    cv=5
)

print(scores)
print(scores.mean())
print(scores.std())
```

- `cv=5` : 데이터를 5개 부분으로 나눠 5번 평가
- 평균 : 모델의 전반적인 성능
- 표준편차 : 성능이 얼마나 흔들리는지 확인
- 표준편차가 작을수록 안정적인 모델
8-3. K-Fold

```plain text
Fold 1 : 검증 / 훈련 / 훈련 / 훈련 / 훈련
Fold 2 : 훈련 / 검증 / 훈련 / 훈련 / 훈련
Fold 3 : 훈련 / 훈련 / 검증 / 훈련 / 훈련
Fold 4 : 훈련 / 훈련 / 훈련 / 검증 / 훈련
Fold 5 : 훈련 / 훈련 / 훈련 / 훈련 / 검증
```

각 부분이 한 번씩 검증 데이터가 된다.

5번의 평가 결과를 평균해 한 번의 분할보다 신뢰도 높은 성능을 구한다.

8-4. Stratified K-Fold

**Stratified K-Fold**

`각 Fold에 클래스 비율이 비슷하게 유지되도록 데이터를 나누는 방법`

```python
from sklearn.model_selection import StratifiedKFold

skf = StratifiedKFold(
    n_splits=5,
    shuffle=True,
    random_state=42
)

scores = cross_val_score(
    model,
    X_train,
    y_train,
    cv=skf
)
```

퇴사자처럼 특정 클래스가 적은 분류 문제에서는 일반 K-Fold보다 Stratified K-Fold가 적합하다.

9-1. 파라미터와 하이퍼파라미터

- 파라미터 : 모델이 데이터에서 직접 학습하는 값
- 하이퍼파라미터 : 모델을 학습하기 전에 사람이 설정하는 값
Random Forest의 대표적인 하이퍼파라미터

- `n_estimators` : 생성할 트리 개수
- `max_depth` : 트리의 최대 깊이
- `min_samples_split` : 노드를 나누기 위한 최소 데이터 수
9-2. GridSearchCV

**GridSearchCV**

`미리 지정한 모든 하이퍼파라미터 조합을 교차검증해 가장 좋은 조합을 찾는 방법`

```python
from sklearn.model_selection import GridSearchCV

param_grid = {
    "n_estimators": [50, 100, 200],
    "max_depth": [3, 5, 10, None],
    "min_samples_split": [2, 5]
}
```

```plain text
트리 개수 3가지
× 깊이 4가지
× 최소 데이터 수 2가지
= 총 24개 조합
```

```python
grid_search = GridSearchCV(
    RandomForestClassifier(
        random_state=42
    ),
    param_grid=param_grid,
    cv=5,
    scoring="accuracy",
    n_jobs=-1
)

grid_search.fit(
    X_train,
    y_train
)
```

- `param_grid` : 탐색할 하이퍼파라미터 후보
- `cv=5` : 각 조합을 5-Fold 교차검증
- `scoring="accuracy"` : 정확도를 기준으로 비교
- `n_jobs=-1` : 사용 가능한 CPU를 모두 활용
```python
print(grid_search.best_params_)
print(grid_search.best_score_)
```

- `best_params_` : 가장 좋은 하이퍼파라미터 조합
- `best_score_` : 가장 좋은 평균 교차검증 점수
- `best_estimator_` : 가장 좋은 설정으로 학습한 모델
9-3. 최종 테스트 평가

```python
best_model = grid_search.best_estimator_

test_score = best_model.score(
    X_test,
    y_test
)

print(test_score)
```

```plain text
훈련 데이터
→ 하이퍼파라미터 탐색과 교차검증

테스트 데이터
→ 모든 선택이 끝난 뒤 최종 성능 확인
```

※ 테스트 데이터는 GridSearchCV의 `fit()`에 사용하면 안 됨

9-4. 탐색 결과 확인

```python
results = pd.DataFrame(
```

10-1. RandomizedSearchCV

**RandomizedSearchCV**

`모든 조합을 확인하지 않고 지정한 횟수만큼 무작위 조합을 선택해 탐색하는 방법`

```python
from sklearn.model_selection import RandomizedSearchCV

param_dist = {
    "n_estimators": [50, 100, 150, 200, 300],
    "max_depth": [3, 5, 7, 10, 15, None],
    "min_samples_split": [2, 3, 4, 5, 8]
}
```

```python
random_search = RandomizedSearchCV(
    RandomForestClassifier(
        random_state=42
    ),
    param_distributions=param_dist,
    n_iter=10,
    cv=5,
    random_state=42,
    n_jobs=-1
)

random_search.fit(
    X_train,
    y_train
)
```

- `n_iter=10` : 전체 후보 중 10개 조합만 무작위로 탐색
- 후보 조합이 많을 때 시간을 줄일 수 있음
- 최적 조합을 놓칠 가능성이 있음
10-2. 탐색 방법 비교


11-1. 과소적합

**과소적합 Underfitting**

`모델이 너무 단순해 훈련 데이터의 패턴조차 충분히 학습하지 못한 상태`

```plain text
훈련 성능 낮음
테스트 성능 낮음
→ 과소적합 가능성
```

해결 방법

- 모델을 더 복잡하게 변경
- 특성을 추가
- 규제를 약하게 설정
- 트리 깊이를 증가
11-2. 과대적합

**과대적합 Overfitting**

`모델이 훈련 데이터를 지나치게 외워 새로운 데이터에서 성능이 낮아지는 상태`

```plain text
훈련 성능 매우 높음
테스트 성능 낮음
→ 과대적합 가능성
```

해결 방법

- 모델을 단순하게 조정
- 트리 깊이 제한
- 규제 강화
- 데이터를 더 수집
- 교차검증 사용
11-3. 하이퍼파라미터와 복잡도

※ `min_samples_split`은 값이 클수록 분기가 어려워져 모델이 단순해짐

12-1. Validation Curve

**Validation Curve 검증 곡선**

`하이퍼파라미터 하나를 바꿔가며 훈련 점수와 검증 점수의 변화를 확인하는 그래프`

```python
from sklearn.model_selection import validation_curve

depth_range = [
    1, 2, 3, 5,
    7, 10, 15, 20
]

train_scores, val_scores = validation_curve(
    RandomForestClassifier(
        random_state=42
    ),
    X_train,
    y_train,
    param_name="max_depth",
    param_range=depth_range,
    cv=5
)
```

```python
train_mean = train_scores.mean(axis=1)
val_mean = val_scores.mean(axis=1)

plt.plot(
    depth_range,
    train_mean,
    marker="o",
    label="훈련 점수"
)

plt.plot(
    depth_range,
    val_mean,
    marker="s",
    label="검증 점수"
)

plt.xlabel("max_depth")
plt.ylabel("정확도")
plt.legend()
plt.show()
```

그래프 해석

```plain text
훈련·검증 점수 모두 낮음
→ 모델이 너무 단순
→ 과소적합

훈련 점수는 높고 검증 점수는 낮음
→ 두 점수의 차이가 큼
→ 과대적합

검증 점수가 가장 높은 지점
→ 적절한 하이퍼파라미터 후보
```

※ 훈련 점수는 모델이 복잡해질수록 계속 높아질 수 있으므로 검증 점수를 기준으로 선택

13-1. Learning Curve

**Learning Curve 학습 곡선**

`훈련 데이터의 양을 늘려가며 훈련 점수와 검증 점수가 어떻게 변하는지 확인하는 그래프`

```python
from sklearn.model_selection import learning_curve
import numpy as np

train_sizes, train_scores, val_scores = learning_curve(
    RandomForestClassifier(
        max_depth=5,
        random_state=42
    ),
    X_train,
    y_train,
    cv=5,
    train_sizes=np.linspace(
        0.1,
        1.0,
        10
    )
)
```

```python
train_mean = train_scores.mean(axis=1)
val_mean = val_scores.mean(axis=1)

plt.plot(
    train_sizes,
    train_mean,
    marker="o",
    label="훈련 점수"
)

plt.plot(
    train_sizes,
    val_mean,
    marker="s",
    label="검증 점수"
)

plt.xlabel("훈련 데이터 개수")
plt.ylabel("정확도")
plt.legend()
plt.show()
```

13-2. Learning Curve 해석

```plain text
훈련·검증 점수가 모두 낮고 가까움
→ 과소적합
→ 데이터를 늘려도 큰 효과가 없을 수 있음
→ 모델을 더 복잡하게 변경

훈련 점수는 높고 검증 점수와 차이가 큼
→ 과대적합
→ 데이터를 더 모으면 도움이 될 수 있음
→ 모델을 단순화하는 것도 필요

데이터가 늘면서 두 점수가 높은 값으로 가까워짐
→ 이상적인 학습 상태
```

13-3. 진단 도구 비교

```plain text
하이퍼파라미터를 어떻게 설정할까?
→ Validation Curve

데이터를 더 모으면 좋아질까?
→ Learning Curve
```

14-1. 이미지를 숫자 데이터로 변환

이미지는 각 픽셀이 RGB 숫자로 이루어져 있다.

```plain text
픽셀 하나
→ [Red, Green, Blue]

사진 한 장
→ 수많은 RGB 데이터
```

```python
import numpy as np
from PIL import Image

img = Image.open(
    "sample_photo.jpg"
).resize((160, 105))

pixels = np.array(img).reshape(-1, 3)

print(pixels.shape)
```

- 각 행 : 픽셀 하나
- 각 열 : R, G, B 값
- 고객 군집화와 동일하게 K-Means 적용 가능
14-2. 대표 색상 추출

```python
from sklearn.cluster import KMeans

K = 6

kmeans_img = KMeans(
    n_clusters=K,
    random_state=42,
    n_init=10
)

kmeans_img.fit(pixels)

palette = (
    kmeans_img
    .cluster_centers_
    .astype(int)
)
```

```plain text
픽셀 군집
→ 비슷한 색끼리 그룹화

군집 중심점
→ 각 그룹의 대표 RGB 색상
```

- `cluster_centers_` : 사진의 대표 색상
- K가 6이면 대표 색상 6개 추출
14-3. 이미지 색상 압축

```python
compressed = palette[
    kmeans_img.labels_
].reshape(
    np.array(img).shape
).astype("uint8")
```

모든 픽셀을 자신이 속한 군집의 대표 색상으로 바꾸면 K가지 색만 사용하는 이미지가 된다.

```plain text
원본 이미지
→ 수많은 색상 사용

K-Means 적용
→ K개의 대표색 추출

모든 픽셀을 대표색으로 교체
→ 색상 수가 줄어든 압축 이미지
```

이 방식을 **색 양자화 Color Quantization**라고 한다.
