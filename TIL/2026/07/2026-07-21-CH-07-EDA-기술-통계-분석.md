# CH 07 (EDA, 기술 통계 분석)

## 📝 오늘 배운 내용 요약

1-1. EDA

**EDA**

`처음 보는 데이터의 구조, 분포, 결측치, 특징을 빠르게 파악하는 과정`

EDA는 본격적인 분석이나 머신러닝 전에 데이터를 이해하기 위해 수행한다.

```plain text
데이터 불러오기
→ 구조 확인
→ 요약 통계 확인
→ 결측치 확인
→ 범주와 분포 확인
→ 필요한 데이터 선택
→ 그룹별 특징 분석
```

이번 실습에서는 직원 데이터를 이용해 EDA를 진행한다.

```plain text
import pandas as pd
import numpy as np

data = {
    "이름": [
        "김민준", "이서연", "박도윤", "최지우", "정하윤",
        "강서준", "조예은", "윤지호", "임수아", "한도현"
    ],
    "나이": [
        29, 34, 41, 26, 38,
        45, 31, np.nan, 27, 33
    ],
    "부서": [
        "개발팀", "마케팅팀", "개발팀", "인사팀", "마케팅팀",
        "개발팀", "인사팀", "마케팅팀", "개발팀", "인사팀"
    ],
    "직무": [
        "Developer", "Marketer", "Developer", "HR", "Marketer",
        "Developer", "HR", "Marketer", "Developer", "HR"
    ],
    "급여": [
        4200, 3800, 5600, 3600, 4100,
        6200, 3900, 4300, 4000, 3700
    ]
}

df = pd.DataFrame(data)
```

2-1. head(), tail(), sample()

```plain text
print(df.head())
print(df.tail())
print(df.sample())
```

- `head()` : 앞에서부터 5개 행 확인
- `tail()` : 뒤에서부터 5개 행 확인
- `sample()` : 무작위로 행 추출
행 개수를 직접 지정할 수도 있다.

```plain text
print(df.head(3))
print(df.tail(3))
print(df.sample(4))
```

`sample()` 결과를 매번 같게 만들려면 `random_state`를 지정한다.

```plain text
print(df.sample(3, random_state=42))
```

```plain text
random_state 지정 안 함
→ 실행할 때마다 다른 행 추출

random_state 지정
→ 실행할 때마다 같은 행 추출
```

4-1. describe()

**기술통계**

`데이터의 중심, 범위, 분포를 요약한 통계값`

```plain text
df.describe()
```

수치형 컬럼에 대해 다음 값을 확인한다.

- `count` : 결측치를 제외한 데이터 개수
- `mean` : 평균
- `std` : 표준편차
- `min` : 최솟값
- `25%` : 1사분위수
- `50%` : 중앙값
- `75%` : 3사분위수
- `max` : 최댓값
문자열 컬럼까지 함께 확인하려면 다음과 같이 작성한다.

```plain text
df.describe(include="all")
```

문자열 컬럼에서는 다음 값이 나타난다.

- `count` : 결측치를 제외한 개수
- `unique` : 고유값 개수
- `top` : 가장 자주 등장한 값
- `freq` : 가장 자주 등장한 횟수

8-1. nlargest()와 nsmallest()

```plain text
print(
    df.nlargest(3, "급여")
)

print(
    df.nsmallest(3, "나이")
)
```

- `nlargest()` : 가장 큰 값부터 추출
- `nsmallest()` : 가장 작은 값부터 추출
```plain text
급여 상위 3명
→ nlargest(3, "급여")

나이가 어린 3명
→ nsmallest(3, "나이")
```

단순히 상위 몇 개를 확인할 때는 전체를 정렬한 뒤 `head()`를 사용하는 것보다 편리하다.

8-2. rank()

**rank**

`값의 크기를 기준으로 순위를 계산`

```plain text
df["급여순위"] = (
    df["급여"]
    .rank(ascending=False)
)

print(
    df[
        ["이름", "급여", "급여순위"]
    ].sort_values("급여순위")
)
```

- `ascending=False` : 큰 값이 1위
- `ascending=True` : 작은 값이 1위
동점이 있으면 기본적으로 평균 순위를 부여한다.

```plain text
df["급여순위"] = df["급여"].rank(
    ascending=False,
    method="min"
)
```

`method="min"`을 사용하면 동점자에게 같은 최소 순위를 부여한다.

13-2. 다중 조건

**AND 조건**

```plain text
result = df[
    (df["부서"] == "개발팀")
    & (df["급여"] > 4000)
]
```

**OR 조건**

```plain text
result = df[
    (df["부서"] == "개발팀")
    | (df["부서"] == "인사팀")
]
```

**NOT 조건**

```plain text
result = df[
    ~(df["부서"] == "개발팀")
]
```

- `&` : 그리고
- `|` : 또는
- `~` : 반대
※ 여러 조건을 사용할 때는 각 조건을 반드시 괄호로 감싸야 함

```plain text
df[
    (df["부서"] == "개발팀")
    & (df["급여"] >= 4000)
]
```

17-1. query()

**query**

`문자열 형태로 조건을 작성해 데이터를 필터링하는 메서드`

```plain text
print(
    df.query(
        "급여 >= 4000"
    )
)
```

여러 조건도 사용할 수 있다.

```plain text
print(
    df.query(
        "부서 == '개발팀' and 나이 < 40"
    )
)
```

외부 변수는 `@`를 붙여 사용한다.

```plain text
result = df.query(
    "나이 >= @age_limit"
)
```

```plain text
일반 필터링
→ 괄호와 &, | 사용

query()
→ 문자열 안에 and, or 사용
```

컬럼명이 띄어쓰기를 포함하면 백틱을 사용해야 한다.

```plain text
df.query(
    "`평균 급여` >= 4000"
)
```

```plain text
전체 직원 데이터
→ 부서별로 나누기
→ 부서별 평균·합계·인원수 계산
```

```plain text
grouped = df.groupby("부서")

print(
    grouped["급여"].mean()
)
```

`groupby()`만 실행하면 그룹을 나눌 뿐 실제 통계는 계산하지 않는다.

```plain text
groupby("부서")
→ 부서별로 데이터 분리

mean()
→ 각 부서의 평균 계산
```

18-2. 기본 집계 함수

```plain text
print(
    df.groupby("부서")["급여"].mean()
)

print(
    df.groupby("부서")["급여"].sum()
)

print(
    df.groupby("부서")["급여"].count()
)

print(
    df.groupby("부서")["급여"].median()
)

print(
    df.groupby("부서")["급여"].max()
)

print(
    df.groupby("부서")["급여"].min()
)
```

- `mean()` : 평균
- `sum()` : 합계
- `count()` : 결측치를 제외한 개수
- `median()` : 중앙값
- `max()` : 최댓값
- `min()` : 최솟값

```plain text
result = (
    df.groupby("부서")[
        ["급여", "나이"]
    ]
    .mean()
```

```plain text
result = (
    df.groupby(
```

```plain text
첫 번째 기준
→ 부서

두 번째 기준

→ 평균 급여 계산
```

19-1. 여러 통계 한 번에 계산

**agg**

`하나의 그룹에 여러 집계 함수를 동시에 적용`

```plain text
result = (
    df.groupby("부서")["급여"]
    .agg([
        "mean",
        "sum",
        "max"
    ])
)

print(result)
```

컬럼마다 다른 통계를 적용할 수도 있다.

```plain text
result = df.groupby("부서").agg({
    "나이": "mean",
    "급여": "sum"
})

print(result)
```

```plain text
나이
→ 평균

급여
→ 합계
```

19-2. Named Aggregation

결과 컬럼명을 직접 지정할 수 있다.

```plain text
result = df.groupby("부서").agg(
    평균급여=("급여", "mean"),
    최대급여=("급여", "max"),
    평균나이=("나이", "mean")
)

print(result)
```

```plain text
새로운 컬럼명
= (계산할 원본 컬럼, 집계 함수)
```

20-1. transform()

**transform**

`그룹별 계산 결과를 원본 데이터와 같은 행 개수로 반환`

```plain text
df["부서평균급여"] = (
    df.groupby("부서")["급여"]
    .transform("mean")
)
```

```plain text
groupby().mean()
→ 부서마다 결과 한 개

groupby().transform("mean")
→ 각 직원 행마다 소속 부서의 평균값 반환
```

개인 급여와 부서 평균을 비교할 수 있다.

```plain text
df["평균과차이"] = (
    df["급여"]
    - df["부서평균급여"]
)
```

```plain text
평균과차이 > 0
→ 부서 평균보다 급여가 높음

평균과차이 < 0
→ 부서 평균보다 급여가 낮음
```

21-1. 그룹 필터링

**filter**

`조건을 만족하는 그룹 전체를 선택`

평균 급여가 4,000 이상인 부서의 직원만 선택한다.

```plain text
result = (
    df.groupby("부서")
    .filter(
        lambda group:
            group["급여"].mean()
            >= 4000
    )
)

print(result)
```

```plain text
각 부서의 평균 급여 계산
→ 조건 확인
→ 조건을 만족한 부서의 모든 직원 유지
```

일반 조건 필터링과의 차이

```plain text
df[df["급여"] >= 4000]
→ 개인 급여를 기준으로 행 선택

groupby().filter()
→ 부서 전체의 통계를 기준으로 그룹 선택
```

22-1. crosstab()

**crosstab**

`두 범주형 컬럼의 조합별 빈도수를 표로 정리`

```plain text
result = pd.crosstab(
    df["부서"],
    df["도시"]
)

print(result)
```

```plain text
행
→ 부서

열
→ 도시

값
→ 해당 조합의 직원 수
```

행 기준 비율로 확인할 수도 있다.

```plain text
ratio = pd.crosstab(
    df["부서"],
    df["도시"],
    normalize="index"
)

print(ratio)
```

- `normalize="index"` : 행별 비율
- `normalize="columns"` : 열별 비율
- `normalize="all"` : 전체 기준 비율
```plain text
normalize="index"
→ 각 부서 안에서 도시의 비율

normalize="columns"
→ 각 도시 안에서 부서의 비율
```

23-1. pivot_table()

**pivot_table**

`행과 열에 범주를 배치하고 수치형 데이터의 통계를 계산`

```plain text
result = df.pivot_table(
    index="부서",

    values="급여"
```

기본 집계 함수는 평균이다.

```plain text
result = df.pivot_table(

    aggfunc=[
        "mean",
        "count"

```

```plain text
crosstab()
→ 범주 조합별 개수 확인

pivot_table()
→ 범주 조합별 평균·합계 등 계산
```

```plain text
df["나이대"] = pd.cut(
    df["나이"],
    bins=[
        0,
        30,
        40,
        100
    ],
    labels=[
        "30세 이하",
        "31~40세",
        "41세 이상"
    ]
)
```

```plain text
print(
    df["나이대"].value_counts()
)
```

```plain text
0~30
→ 30세 이하

30~40
→ 31~40세

40~100
→ 41세 이상
```

※ 구간의 경계값이 어느 범주에 포함되는지 확인해야 함

24-2. qcut()

**qcut**

`각 구간에 비슷한 개수의 데이터가 들어가도록 나누는 방법`

```plain text
df["급여등급"] = pd.qcut(
    df["급여"],

        "하",

)
```

```plain text
cut()
→ 사용자가 숫자 범위를 직접 지정

qcut()
→ 데이터 개수가 비슷하도록 자동 분할
```

```plain text
데이터 미리보기

분포와 통계 확인

→ loc, iloc, 조건 필터링

그룹별 특징 분석
→ groupby(), agg(), transform(), filter()

표 형태로 요약
→ crosstab(), pivot_table()

연속형 값을 구간화
→ cut(), qcut()
```

- EDA : 데이터를 분석하기 전에 구조와 특징을 탐색하는 과정
- `head()` : 데이터 앞부분 확인
- `tail()` : 데이터 뒷부분 확인
- `sample()` : 무작위 행 확인
- `shape` : 행과 열의 개수
- `dtypes` : 컬럼별 자료형
- `info()` : 자료형과 결측치 여부를 포함한 데이터 구조 확인
- `describe()` : 수치형 컬럼의 기술통계 확인
- `describe(include="all")` : 문자열을 포함한 전체 컬럼 요약
- `isnull()`·`isna()` : 결측치 여부 확인
- `unique()` : 고유값 목록 확인
- `nunique()` : 고유값 개수 확인
- `value_counts()` : 값별 빈도수 확인
- `normalize=True` : 빈도수를 비율로 출력
- `sort_values()` : 특정 컬럼 기준 정렬
- `nlargest()` : 가장 큰 값부터 일부 추출
- `nsmallest()` : 가장 작은 값부터 일부 추출
- `rank()` : 값의 크기에 따른 순위 계산
- `idxmax()`·`idxmin()` : 최댓값·최솟값이 있는 인덱스 확인
- `select_dtypes()` : 자료형에 따라 컬럼 선택
- 컬럼 하나 선택 결과는 Series
- 컬럼 여러 개 선택 결과는 DataFrame
- `loc[]` : 라벨을 기준으로 데이터 선택
- `iloc[]` : 정수 위치를 기준으로 데이터 선택
- `at[]`·`iat[]` : 단일 값에 빠르게 접근
- 다중 조건에서는 `&`, `|`, `~` 사용
- 각 조건은 반드시 괄호로 감싸야 함
- `isin()` : 여러 값 중 하나에 해당하는 행 선택
- `between()` : 특정 범위 안의 값 선택
- `str.contains()` : 문자열 포함 여부 확인
- `set_index()` : 특정 컬럼을 인덱스로 설정
- `reset_index()` : 기본 숫자 인덱스로 복원
- `query()` : 문자열 형태로 조건 필터링
- `groupby()` : 특정 기준으로 데이터를 나누어 통계 계산
- `agg()` : 여러 집계 함수를 한 번에 적용
- Named Aggregation : 집계 결과의 컬럼명을 직접 지정
- `transform()` : 그룹별 결과를 원본 행 개수에 맞춰 반환
- `filter()` : 그룹 통계를 기준으로 그룹 전체 선택
- `crosstab()` : 범주 조합별 빈도수 확인
- `pivot_table()` : 범주별 수치 통계를 표 형태로 정리
- `cut()` : 사용자가 지정한 숫자 구간으로 분류
- `qcut()` : 데이터 개수가 비슷하도록 구간 분류
