## 📝 오늘 배운 내용 요약

1-1. 데이터 시각화

**데이터 시각화**

`데이터를 그래프나 도표로 표현해 숫자만으로 찾기 어려운 특징을 쉽게 확인하는 과정`

```plain text
표와 숫자
→ 그래프로 표현
→ 분포·차이·관계 확인
→ 의미 해석
→ 인사이트 도출
```

데이터 시각화는 단순히 그래프를 예쁘게 그리는 것이 아니라 데이터에서 의미를 발견하고 다른 사람에게 효과적으로 전달하는 과정이다.

1-2. 데이터 시각화가 필요한 이유

- 데이터가 어떤 범위에 퍼져 있는지 확인
- 범주별 값의 크기 비교
- 시간이나 순서에 따른 변화 확인
- 다른 값과 크게 차이 나는 이상치 발견
- 두 변수 사이의 관계 확인
- 분석 결과를 직관적으로 전달
```plain text
무엇을 확인하고 싶은가?
→ 목적에 맞는 그래프 선택
```

4-1. plt.plot()

**선그래프**

`시간이나 순서에 따라 값이 어떻게 변하는지 선으로 표현하는 그래프`

```plain text
titanic = pd.read_csv("titanic.csv")

titanic["연령대"] = pd.cut(
    titanic["age"],
    bins=[0, 10, 20, 30, 40, 50, 60, 80],
    labels=[
        "0대", "10대", "20대", "30대",
        "40대", "50대", "60대 이상"
    ]
)

age_survival = (
    titanic
    .groupby("연령대", observed=True)["survived"]
    .mean()
)
```

```plain text
plt.plot(
    age_survival.index,
    age_survival.values
)

plt.title("연령대별 생존율")
plt.xlabel("연령대")
plt.ylabel("생존율")

plt.show()
```

- `x` : 연령대
- `y` : 연령대별 평균 생존율
- 순서가 있는 연령대별 변화 확인에 적합
4-2. 선그래프 옵션

```plain text
plt.plot(
    age_survival.index,
    age_survival.values,
    marker="o",
    color="red",
    linestyle="--"
)
```

- `marker` : 각 데이터 위치의 점 모양
- `color` : 선 색상
- `linestyle` : 선 모양
대표적인 옵션

```plain text
marker
→ "o", "s", "^", "x", "*"

linestyle
→ "-", "--", "-.", ":"

color
→ "red", "blue", "purple", "skyblue"
```

6-1. plt.scatter()

**산점도**

`두 수치형 변수의 관계를 점으로 표현하는 그래프`

```plain text
plt.scatter(
    titanic["age"],
    titanic["fare"],
    s=20,
    alpha=0.5
)

plt.title("나이와 요금의 관계")
plt.xlabel("나이")
plt.ylabel("요금")

plt.show()
```

- 각 행이 하나의 점으로 표현
- `s` : 점의 크기
- `alpha` : 점의 투명도
- 점이 많을 때 투명도를 낮추면 겹친 정도를 확인하기 쉬움
산점도에서는 다음 내용을 확인할 수 있다.

```plain text
x가 증가할수록 y도 증가하는가?
→ 양의 관계

x가 증가할수록 y는 감소하는가?
→ 음의 관계

일정한 방향이 없는가?
→ 뚜렷한 관계가 약함

다른 점과 멀리 떨어진 점이 있는가?
→ 이상치 가능성
```

※ 산점도에서 관계가 보인다고 반드시 원인과 결과 관계라는 의미는 아님

7-1. plt.hist()

**히스토그램**

`연속적인 숫자 데이터를 일정한 구간으로 나누고 구간별 데이터 개수를 표현하는 그래프`

```plain text
plt.hist(
    titanic["age"].dropna(),
    bins=8,
    color="orange",
    edgecolor="black"
)

plt.title("승객 나이 분포")
plt.xlabel("나이")
plt.ylabel("승객 수")

plt.show()
```

- `dropna()` : 결측치 제거
- `bins` : 구간 개수
- `edgecolor` : 막대 테두리 색상
```plain text
bins가 작음
→ 넓은 구간으로 단순하게 표현

bins가 큼
→ 세밀하게 표현하지만 그래프가 복잡해질 수 있음
```

히스토그램을 통해 확인할 수 있는 내용

- 값이 어느 구간에 많이 모였는지
- 한쪽으로 치우친 분포인지
- 봉우리가 하나인지 여러 개인지
- 극단적인 값이 존재하는지
※ 막대그래프는 범주 비교, 히스토그램은 연속형 데이터의 분포 확인에 사용

8-1. plt.pie()

**원그래프**

`전체에서 각 항목이 차지하는 비율을 원의 조각으로 표현하는 그래프`

```plain text
class_counts = (
    titanic["pclass"]
    .value_counts()
    .sort_index()
)
```

```plain text
plt.pie(
    class_counts.values,
    labels=[
        f"{pclass}등석"
        for pclass in class_counts.index
    ],
    autopct="%1.1f%%",
    startangle=90
)

plt.title("좌석 등급별 승객 비율")
plt.show()
```

- `labels` : 조각별 항목 이름
- `autopct` : 비율 표시 형식
- `startangle` : 그래프가 시작하는 각도
```plain text
"%1.1f%%"
→ 소수점 첫째 자리까지 표시

"%1.2f%%"
→ 소수점 둘째 자리까지 표시
```

※ 항목이 많거나 비율 차이가 작으면 원그래프보다 막대그래프가 비교하기 쉬움

9-1. 박스플롯

**박스플롯**

`데이터의 중앙값, 사분위수, 분포 범위와 이상치를 함께 보여주는 그래프`

```plain text
plt.boxplot(
    titanic["fare"].dropna()
)

plt.title("승객 요금 분포")
plt.ylabel("요금")

plt.show()
```

박스플롯의 주요 구성

- 상자의 아래쪽 : 1사분위수
- 상자 안의 선 : 중앙값
- 상자의 위쪽 : 3사분위수
- 수염 : 일반적인 데이터 범위
- 수염 밖의 점 : 이상치 후보
```plain text
상자가 길다
→ 가운데 50% 데이터의 범위가 넓음

중앙값이 상자의 한쪽에 치우침
→ 분포가 한쪽으로 치우쳤을 가능성

수염 밖에 점이 많음
→ 이상치 후보가 많음
```

12-1. sns.barplot()

```plain text
plt.show()
```

Seaborn은 원본 데이터만 전달해도 각 좌석 등급의 평균 생존율을 자동으로 계산한다.

```plain text
Seaborn
→ 원본 DataFrame과 컬럼명만 지정
→ 평균 계산과 그래프 생성을 함께 처리
```

- `hue` : 추가 범주를 색상으로 구분

19-1. twinx()

**이중 축**

`단위가 다른 두 지표를 하나의 그래프에 함께 표현하는 방법`

```plain text
class_info = (
    titanic
    .groupby("pclass")
    .agg(
        생존율=("survived", "mean"),
        평균요금=("fare", "mean")
    )
)
```

```plain text
fig, ax1 = plt.subplots()

ax1.bar(
    class_info.index,
    class_info["생존율"],
    alpha=0.6
)

ax1.set_xlabel("좌석 등급")
ax1.set_ylabel("생존율")

ax2 = ax1.twinx()

ax2.plot(
    class_info.index,
    class_info["평균요금"],
    marker="o"
)

ax2.set_ylabel("평균 요금")

plt.title("좌석 등급별 생존율과 평균 요금")
plt.show()
```

- 왼쪽 y축 : 생존율
- 오른쪽 y축 : 평균 요금
- 서로 단위가 다른 값을 함께 비교 가능
※ 이중 축은 해석이 혼동될 수 있으므로 축 이름과 단위를 명확히 표시해야 함

```plain text
범주별 비교

시간·순서에 따른 변화
→ 선그래프

수치형 데이터 분포
→ 히스토그램

분포와 이상치
→ 박스플롯

두 변수의 관계
→ 산점도
```

22-2. 제목과 축을 명확하게 작성

```plain text
plt.title("좌석 등급별 평균 생존율")
plt.xlabel("좌석 등급")

```

`그래프 1`, `결과`처럼 의미가 없는 제목보다 무엇을 비교하는 그래프인지 구체적으로 작성해야 한다.

22-3. 하나의 그래프에 너무 많은 내용을 넣지 않기

- 선을 너무 많이 겹치지 않음
- 지나치게 많은 색상 사용 금지
- 범주가 많으면 그래프를 나누어 표현
- 중요하지 않은 장식은 줄이기
22-4. 축을 왜곡하지 않기

- 막대그래프의 y축은 일반적으로 0부터 시작
- 필요 이상으로 좁은 축 범위를 사용하지 않음
- 로그 축이나 이중 축을 사용하면 반드시 표시
22-5. 색상을 의미 있게 사용

```plain text
같은 의미의 항목
→ 같은 색상 계열

서로 다른 집단
→ 구분 가능한 색상

높고 낮은 정도
→ 연속적인 색상

긍정·부정
→ 대비되는 색상
```

22-6. 그래프를 만든 뒤 해석하기

```plain text
그래프 생성
→ 가장 큰 값과 작은 값 확인
→ 전체적인 추세 확인
→ 이상치 확인
→ 집단 간 차이 확인
→ 분석 목적과 연결
```

그래프만 제시하지 않고 그래프에서 무엇을 발견했는지 설명해야 한다.

- `sns.heatmap()` : 상관관계 행렬 표현
- `sns.pairplot()` : 여러 변수의 관계를 한 번에 확인
- `hue` : 범주에 따라 색상 구분
- `plt.subplot()` : 그래프 영역을 하나씩 지정
- `plt.subplots()` : Figure와 여러 Axes를 한 번에 생성
- `suptitle()` : 여러 그래프의 전체 제목
- `tight_layout()` : 그래프 간 겹침 방지
- `twinx()` : 서로 단위가 다른 두 지표를 이중 축으로 표현
- Plotly는 마우스로 값을 확인하고 확대할 수 있는 인터랙티브 그래프 제공
- `px.line()` : 인터랙티브 선그래프
- `px.bar()` : 인터랙티브 막대그래프
- `px.scatter()` : 인터랙티브 산점도
- `px.histogram()` : 인터랙티브 히스토그램
- `px.pie()` : 인터랙티브 원그래프
- `hover_data` : 마우스 오버 시 추가 정보 표시
- `update_layout()` : Plotly 제목, 축 이름, 크기 설정
- 정적 보고서에는 Matplotlib, 통계 탐색에는 Seaborn, 대화형 탐색에는 Plotly가 적합
- 좋은 시각화는 목적에 맞는 그래프를 선택하고 복잡한 정보를 정확하고 간단하게 전달해야 함
