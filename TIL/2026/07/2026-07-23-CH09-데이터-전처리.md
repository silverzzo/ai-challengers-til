1-1. 데이터 전처리

**데이터 전처리**

`수집한 원본 데이터를 분석과 머신러닝에 사용할 수 있는 형태로 정리하는 과정`

실제 데이터에는 결측치, 이상치, 잘못된 자료형, 중복값 등이 포함될 수 있다.

```plain text
원본 데이터
→ 결측치 처리
→ 이상치 처리
→ 자료형 변환
→ 중복 제거
→ 데이터 병합
→ 분석 가능한 데이터
```

전처리가 제대로 되지 않으면 계산 결과가 왜곡되거나 코드 실행 중 오류가 발생할 수 있다.

```plain text
import pandas as pd

df = pd.read_csv("orders.csv")

print(df.head())
print(df.info())
```

- `head()` : 데이터 앞부분 확인
- `info()` : 컬럼, 자료형, 결측치 개수 확인
- `describe()` : 수치형 데이터의 요약 통계 확인

2-1. 결측치

**결측치 Missing Value**

`데이터에 값이 비어 있는 상태`

Pandas에서는 결측치를 주로 `NaN`으로 표현한다.

```plain text
수량      NaN
카테고리  NaN
배송평점  NaN
```

결측치가 생기는 원인

- 사용자가 값을 입력하지 않음
- 데이터를 수집하는 과정에서 누락
- 서로 다른 데이터를 합치는 과정에서 값이 맞지 않음
- 잘못된 자료형 변환으로 값이 사라짐
2-2. 결측치 확인

```plain text
print(df.isnull())
print(df.isnull().sum())
```

- `isnull()` 또는 `isna()` : 결측치이면 `True`
- `notnull()` 또는 `notna()` : 결측치가 아니면 `True`
- `sum()` : 컬럼별 결측치 개수 계산
```plain text
missing_ratio = (
    df.isnull().sum()
    / len(df)
    * 100
)

print(missing_ratio)
```

결측치 비율도 함께 확인하면 삭제 또는 대체 방법을 결정하는 데 도움이 된다.

2-3. 결측치 삭제

**dropna**

`결측치가 포함된 행이나 컬럼을 제거하는 메서드`

```plain text
# 결측치가 하나라도 있는 행 제거
df_drop = df.dropna()
```

```plain text
# 결측치가 하나라도 있는 컬럼 제거
df_drop_col = df.dropna(axis=1)
```

- `axis=0` : 행 기준
- `axis=1` : 컬럼 기준
- 기본값은 결측치가 하나라도 있으면 제거
```plain text
# 모든 값이 결측치인 행만 제거
df_drop = df.dropna(how="all")
```

```plain text
# 특정 컬럼에 결측치가 있는 행만 제거
df_drop = df.dropna(
    subset=["수량"]
)
```

```plain text
# 결측치가 아닌 값이 8개 이상인 행만 유지
df_drop = df.dropna(
    thresh=8
)
```

- `subset` : 확인할 컬럼 지정
- `how="any"` : 결측치가 하나라도 있으면 제거
- `how="all"` : 모든 값이 결측치일 때만 제거
- `thresh` : 결측치가 아닌 값의 최소 개수
※ 결측치가 적고 해당 행을 삭제해도 데이터 손실이 크지 않을 때 사용

2-4. 결측치 대체

**fillna**

`결측치를 다른 값으로 채우는 메서드`

```plain text
df["수량"] = df["수량"].fillna(0)
```

모든 결측치를 0으로 채울 수도 있지만 컬럼의 의미를 고려해야 한다.

```plain text
수량의 결측치 → 0이 의미 있을 수 있음

카테고리의 결측치 → 0을 넣으면 부자연스러움
```

수치형 데이터는 평균이나 중앙값으로 채울 수 있다.

```plain text
df["수량"] = df["수량"].fillna(
    df["수량"].mean()
)
```

```plain text
df["배송평점"] = df["배송평점"].fillna(
    df["배송평점"].median()
)
```

범주형 데이터는 최빈값으로 채울 수 있다.

```plain text
mode_value = df["카테고리"].mode()[0]

df["카테고리"] = (
    df["카테고리"]
    .fillna(mode_value)
)
```

- 평균 `mean()` : 전체 값의 평균
- 중앙값 `median()` : 정렬했을 때 가운데 값
- 최빈값 `mode()` : 가장 자주 등장하는 값
2-5. 컬럼별 다른 방식 적용

```plain text
df = df.fillna({
    "수량": df["수량"].mean(),
    "카테고리": df["카테고리"].mode()[0],
    "배송평점": df["배송평점"].median()
})
```

컬럼의 의미와 분포에 따라 서로 다른 방식으로 처리해야 한다.

```plain text
수량
→ 평균 또는 중앙값

카테고리
→ 최빈값 또는 "미분류"

배송평점
→ 중앙값
```

2-6. 앞·뒤 값으로 채우기

시간 순서가 있는 데이터에서는 앞이나 뒤의 값으로 결측치를 채울 수 있다.

```plain text
# 이전 값으로 채우기
df["수량"] = df["수량"].ffill()
```

```plain text
# 다음 값으로 채우기
df["수량"] = df["수량"].bfill()
```

- `ffill()` : 앞의 값으로 채움
- `bfill()` : 뒤의 값으로 채움
- 시계열이나 순서가 중요한 데이터에서 사용
2-7. 보간법

**보간 Interpolation**

`결측치 앞뒤의 값을 이용해 중간값을 추정하는 방법`

```plain text
df["배송평점"] = (
    df["배송평점"]
    .interpolate()
)
```

예시

```plain text
3.0, NaN, 5.0
→ 3.0, 4.0, 5.0
```

연속적으로 변하는 수치형 데이터에 적합하다.

2-8. dropna와 fillna

```plain text
결측치가 적고 삭제해도 되는가?
→ dropna()

행을 유지해야 하는가?
→ fillna()

값이 시간 순서대로 변하는가?
→ ffill(), bfill(), interpolate()
```

※ `fillna()` 결과를 변수에 다시 저장하지 않으면 원본 데이터는 바뀌지 않음

```plain text
df["수량"] = df["수량"].fillna(0)
```

3-1. 이상치

**이상치 Outlier**

`다른 데이터와 비교했을 때 지나치게 크거나 작은 값`

예시

```plain text
일반적인 주문 수량
→ 1, 2, 3, 4, 5

이상치
→ 50, 60
```

이상치는 다음과 같은 원인으로 발생할 수 있다.

- 입력 실수
- 측정 오류
- 실제로 발생한 특이한 사건
- 단위가 다른 데이터의 혼합
※ 값이 크거나 작다고 무조건 삭제하면 안 되며 실제 의미를 먼저 확인해야 함

3-2. describe로 이상치 확인

```plain text
print(df["수량"].describe())
```

```plain text
50% 중앙값은 3
최댓값은 60

→ 대부분의 값과 최댓값의 차이가 매우 큼
→ 이상치 가능성
```

평균과 중앙값의 차이도 확인할 수 있다.

```plain text
print(df["수량"].mean())
print(df["수량"].median())
```

이상치가 있으면 평균이 크게 영향을 받을 수 있다.

3-3. 시각화로 이상치 확인

```plain text
import matplotlib.pyplot as plt

plt.boxplot(
    df["수량"].dropna()
)

plt.ylabel("수량")
plt.show()
```

Box Plot에서 수염 밖에 표시되는 점은 이상치 후보이다.

```plain text
plt.hist(

plt.show()
```

※ 시각화만으로 제거 여부를 결정하지 않고 데이터의 의미와 함께 판단

3-4. IQR

**IQR 사분위수 범위**

`데이터 가운데 50%가 포함된 범위`

```plain text
IQR = Q3 - Q1
```

- `Q1` : 하위 25% 지점
- `Q3` : 하위 75% 지점
일반적인 이상치 기준

```plain text
하한선 = Q1 - 1.5 × IQR
상한선 = Q3 + 1.5 × IQR
```

```plain text
Q1 = df["수량"].quantile(0.25)
Q3 = df["수량"].quantile(0.75)

IQR = Q3 - Q1

lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR
```

이상치 행 찾기

```plain text
outliers = df[
    (df["수량"] < lower)
    | (df["수량"] > upper)
]

print(outliers)
```

- `|` : 또는
- 정상 범위보다 작거나 큰 값을 이상치로 판단
3-5. Z-score

**Z-score 표준점수**

`각 값이 평균에서 표준편차 몇 배만큼 떨어져 있는지 나타내는 값`

```plain text
Z-score
= (현재값 - 평균) / 표준편차
```

```plain text
mean = df["수량"].mean()
std = df["수량"].std()

z_score = (
    df["수량"] - mean
) / std
```

```plain text
outliers = df[
    z_score.abs() > 3
]
```

- `abs()` : 절댓값
- 보통 절댓값이 3보다 크면 이상치 후보
- 수업이나 데이터 기준에 따라 2를 사용할 수도 있음
Scipy를 이용하면 더 간단하게 계산할 수 있다.

```plain text
from scipy.stats import zscore

z_score = zscore(
    df["수량"].dropna()
)
```

3-6. IQR과 Z-score

```plain text
분포가 한쪽으로 치우쳤는가?
→ IQR

정규분포에 가까운가?
→ Z-score
```

3-7. 이상치 제거

```plain text
df_removed = df[
    (df["수량"] >= lower)
    & (df["수량"] <= upper)
]
```

- `&` : 그리고
- 하한선과 상한선 사이의 데이터만 유지
- 이상치 행 자체가 잘못된 데이터일 때 사용
3-8. 이상치 대체

**clip**

`범위를 벗어난 값을 하한선이나 상한선으로 제한하는 방법`

```plain text
df["수량_clip"] = (
    df["수량"]
    .clip(
        lower=lower,
        upper=upper
    )
)
```

```plain text
수량 60
상한선 8

→ 60을 삭제하지 않고 8로 변경
```

- 데이터 개수를 유지할 수 있음
- 극단적인 값의 영향만 줄임
- 이상치도 실제 관측값일 수 있을 때 고려
```plain text
이상치가 명백한 오류인가?
→ 제거

행을 유지해야 하는가?
→ clip으로 경계값 대체

실제 중요한 사건인가?
→ 삭제하지 않고 별도로 분석
```

4-2. astype()

**astype**

`Series 또는 DataFrame의 자료형을 지정한 형태로 변환`

```plain text
df["수량"] = df["수량"].astype(int)
```

하지만 쉼표나 문자가 포함된 값은 바로 정수로 바꿀 수 없다.

```plain text
"89000"
→ int 변환 가능

"89,000"
→ 콤마 때문에 바로 변환 불가능
```

문자를 정리한 뒤 변환해야 한다.

```plain text
df["단가"] = (
    df["단가"]
    .str.replace(",", "", regex=False)
    .astype(int)
)
```

- `.str` : 문자열 메서드 사용
- `replace()` : 특정 문자를 다른 문자로 변경
- `regex=False` : 일반 문자열로 처리
4-3. pd.to_numeric()

**pd.to_numeric**

`문자열을 숫자로 변환하는 함수`

```plain text
df["단가"] = pd.to_numeric(
    df["단가"],
    errors="coerce"
)
```

`errors` 옵션

- `"raise"` : 변환할 수 없으면 오류 발생
- `"coerce"` : 변환할 수 없는 값을 `NaN`으로 변경
- `"ignore"` : 변환하지 않고 원래 값 유지
```plain text
messy = pd.Series([
    "100",
    "200",
    "오류"
])

result = pd.to_numeric(
    messy,
    errors="coerce"
)
```

```plain text
100
200
NaN
```

실무에서는 먼저 `errors="coerce"`로 잘못된 값을 찾은 뒤 결측치 처리를 할 수 있다.

4-5. 날짜 자료형 변환

`문자열을 날짜 자료형으로 변환하는 함수`

```plain text
df["주문일"] = pd.to_datetime(
```

```plain text
문자열 "2026-07-31"

datetime 2026-07-31
→ 연도·월·요일 계산 가능
```

날짜 변환이 어려운 값은 `NaT`로 바꿀 수 있다.

```plain text
df["주문일"] = pd.to_datetime(
    df["주문일"],
```

```plain text
    "고객ID",
    "상품명"
]
```

4-10. 중복 확인

**duplicated**

```plain text
print(df.duplicated())
print(df.duplicated().sum())
```

중복된 행만 확인할 수 있다.

```plain text
duplicate_rows = df[
```

- `keep=False` : 중복된 모든 행을 표시
특정 컬럼을 기준으로 중복을 확인할 수도 있다.

5-1. 데이터 병합

서로 다른 파일에 나누어진 정보를 하나의 표로 합치는 과정이다.

```plain text
주문 데이터
→ 주문번호·고객ID·상품·수량

고객 데이터
→ 고객ID·고객명·등급

고객ID 기준으로 결합
→ 주문 정보 + 고객 정보
```

대표적인 방법

- `concat()` : 표를 단순히 이어붙임
- `merge()` : 특정 키를 기준으로 값을 맞춰 결합
- `join()` : 인덱스를 기준으로 결합
5-2. concat()

**pd.concat**

`여러 DataFrame을 행 또는 열 방향으로 이어붙이는 함수`

세로로 합치기

```plain text
all_orders = pd.concat(
    [
        orders_june,
        orders_july
    ],
    axis=0,
    ignore_index=True
)
```

- `axis=0` : 행 방향
- 컬럼 구조가 같은 데이터를 위아래로 연결
- `ignore_index=True` : 인덱스를 0부터 다시 생성
```plain text
6월 주문
+
7월 주문
→ 전체 주문
```

가로로 합치기

```plain text
combined = pd.concat(
    [
        df_a,
        df_b
    ],
    axis=1
)
```

- `axis=1` : 열 방향
- 인덱스가 같은 행끼리 옆으로 연결
※ 가로 결합에서는 행의 순서와 인덱스가 정확히 같은지 확인해야 함

5-3. merge()

**pd.merge**

`기준이 되는 컬럼의 값이 같은 행끼리 정확하게 연결하는 함수`

```plain text
merged = pd.merge(
    orders,
    customers,
    on="고객ID"
)
```

- `on` : 양쪽 DataFrame에서 사용할 기준 키
- 기본 결합 방식은 `inner`
```plain text
orders의 고객ID C001
customers의 고객ID C001

→ 같은 행으로 결합
```

5-4. merge의 how

**inner**

`양쪽 데이터에 모두 존재하는 키만 유지`

```plain text
inner_df = pd.merge(
    orders,
    customers,
    on="고객ID",
    how="inner"
)
```

**left**

`왼쪽 데이터의 모든 행을 유지`

```plain text
left_df = pd.merge(
    orders,
    customers,
    on="고객ID",
    how="left"
)
```

왼쪽에는 있지만 오른쪽에는 없는 값은 `NaN`으로 채워진다.

**right**

`오른쪽 데이터의 모든 행을 유지`

```plain text
right_df = pd.merge(
    orders,
    customers,
    on="고객ID",
    how="right"
)
```

**outer**

`양쪽 데이터의 모든 행을 유지`

```plain text
outer_df = pd.merge(
    orders,
    customers,
    on="고객ID",
    how="outer"
)
```

```plain text
양쪽에 있는 고객만 필요한가?
→ inner

주문 데이터는 모두 유지해야 하는가?
→ left

고객 명단을 모두 유지해야 하는가?
→ right

누락 여부까지 전체 확인해야 하는가?
→ outer
```

5-5. 기준 컬럼명이 다른 경우

```plain text
merged = pd.merge(
    orders,
    customers,
    left_on="고객ID",
    right_on="회원번호",
    how="left"
)
```

- `left_on` : 왼쪽 DataFrame의 기준 컬럼
- `right_on` : 오른쪽 DataFrame의 기준 컬럼
5-6. join()

**join**

`인덱스를 기준으로 DataFrame을 결합하는 메서드`

인덱스가 기준 키로 설정되어 있을 때 편리하다.

```plain text
import pandas as pd

df = pd.read_csv("orders.csv")

# 문자열 정리
df["카테고리"] = (
    df["카테고리"]
    .str.strip()
)

# 숫자 변환
df["단가"] = (
    df["단가"]
    .str.replace(",", "", regex=False)
)

df["단가"] = pd.to_numeric(
    df["단가"],
    errors="coerce"
)

# 날짜 변환
df["주문일"] = pd.to_datetime(
    df["주문일"],
    errors="coerce"
)

# 결측치 처리
df["수량"] = df["수량"].fillna(
    df["수량"].median()
)

df["카테고리"] = (
    df["카테고리"]
    .fillna("미분류")
)

# 중복 제거
df = df.drop_duplicates(
    subset=["주문번호"]
)

# 파생변수 생성
df["주문금액"] = (
    df["단가"]
    * df["수량"]
)
```

```plain text
→ 자료형 변환
→ 결측치 처리
→ 이상치 처리
→ 중복 제거
→ 병합
→ 새로운 컬럼 생성
→ 결과 검증
```

## 💭 오늘의 회고

1. **배운 점**
- 데이터 전처리 : 원본 데이터를 분석 가능한 형태로 정리하는 과정
- `isnull()`·`isna()` : 결측치 위치 확인
- `dropna()` : 결측치가 있는 행이나 컬럼 삭제
- `fillna()` : 결측치를 다른 값으로 대체
- 수치형 결측치 : 평균 또는 중앙값 활용
- 범주형 결측치 : 최빈값 또는 별도 범주 활용
- `ffill()` : 이전 값으로 결측치 채우기
- `bfill()` : 다음 값으로 결측치 채우기
- `interpolate()` : 앞뒤 값을 이용해 결측치 보간
- 이상치 : 다른 값과 지나치게 차이가 나는 데이터
- IQR : 사분위수를 이용해 이상치를 찾는 방법
- Z-score : 평균에서 표준편차 몇 배 떨어졌는지 계산
- `clip()` : 이상치를 상한선·하한선 범위로 제한
- `astype()` : 자료형을 명시적으로 변환
- `pd.to_numeric()` : 문자열을 숫자로 변환
- `errors="coerce"` : 변환할 수 없는 값을 결측치로 변경
- `str.strip()` : 문자열 앞뒤 공백 제거
- `pd.to_datetime()` : 문자열을 날짜 자료형으로 변환
- `.dt` : 날짜에서 연도, 월, 일, 요일 추출
- `replace()` : 특정 값을 다른 값으로 치환
- `map()` : Series 전체에 매핑 규칙 또는 함수 적용
- `rename()` : 컬럼명이나 인덱스명 변경
- `duplicated()` : 중복 데이터 확인
- `drop_duplicates()` : 중복 데이터 제거
- `concat()` : 같은 구조의 데이터를 행 또는 열 방향으로 연결
- `merge()` : 공통 키를 기준으로 서로 다른 정보를 결합
- `inner` : 양쪽에 공통으로 존재하는 데이터만 유지
- `left` : 왼쪽 데이터를 모두 유지
- `right` : 오른쪽 데이터를 모두 유지
- `outer` : 양쪽 데이터를 모두 유지
- `pivot_table()` : 범주별 합계·평균·개수를 표 형태로 집계
- JSON : 키와 값의 구조로 데이터를 표현하는 형식
- `json_normalize()` : 중첩 JSON을 DataFrame 형태로 변환
- `apply()` : Series·DataFrame에 사용자 함수를 적용
- `axis=0` : 열 단위로 함수 적용
